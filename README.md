# Resume Description Matcher

Resume Description Matcher is a web application that compares a candidate's resume with a job description and calculates a similarity score.

## Features
- Upload or paste resume
- Enter job description
- Keyword and skill matching
- Resume-job match percentage
- Suggestions for missing skills

## Tech Stack

Frontend
- HTML
- CSS
- JavaScript
- React

Backend
- Node.js
- Express.js

## How to Run

1. Clone the repository
git clone https://github.com/Sameermd25/ResumeDescriptionMatcher.git

2. Install dependencies
npm install

3. Start server
npm start
